# Rabbit — универсальный лаунчер Minecraft

## Авторизация
- Вход через **Ely.by** или просто по нику (offline-mode)
- **Скины Ely.by в игре**, в том числе на серверах (через authlib-injector)

## Сборки
- У каждой версии свои папки: mods, resourcepacks, shaderpacks, saves, config
- **Общие assets и libraries** между сборками, чтобы одни и те же файлы не скачивались повторно
- **Автоскачивание Java**: нужная версия подбирается под версию игры автоматически

## Принципы
- Простой минималистичный дизайн
- Максимальная легковесность
- Открытый код на GitHub

## Стек
- Go + Wails v2
- Фронтенд: Svelte (или vanilla JS), без тяжёлых UI-фреймворков
- Минимум внешних зависимостей
- Только для Windows
